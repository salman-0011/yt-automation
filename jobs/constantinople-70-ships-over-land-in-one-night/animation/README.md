# Animation (2.5D cartoon)

Motion Canvas (TypeScript, best for map/diagram motion):
  cd animation/motion-canvas && npm install && npm run serve
Manim (Python, best for mechanisms/math):
  cd animation/manim && manim render -qm --format=mp4 scene.py Scene01
Rules: one subject, one camera move, one action per scene. Maps only from verified base data. All text/labels in CapCut, never generated inside the animation.
